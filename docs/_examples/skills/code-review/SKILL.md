# Code review

1. Read the change and its surrounding code before drawing conclusions.
2. Check correctness, edge cases, and whether tests cover the new behavior.
3. Explain actionable findings with a concrete example or reproduction.
4. State what you could not verify. Do not claim to have run tests you did not run.
